状态总览

OpenWrt 宿主机

通过 SSH 到宿主机执行 poweroff。宿主机地址留空时自动取容器默认网关（host 网络模式下即 OpenWrt 本身）。执行前会二次确认，关机后需手动按电源键恢复。

配置

DDNS（仅 Cloudflare API Token）

Token 权限：Zone → DNS → Edit，限定到该域名所在 Zone。记录强制 proxied=false（DNS only），否则 5155 走 Cloudflare 代理不通。

Win PC（可多台，点“添加 PC”新增）

PC 端前置：设置 → 应用 → 可选功能 → 添加 OpenSSH 服务器，服务自动启动，防火墙放行 22 端口；用管理员账号。开机需 BIOS/网卡开启 Wake-on-LAN，且关机是真关机（关闭 Windows 快速启动，否则 WOL 常失效）。
